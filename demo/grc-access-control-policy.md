# Synthetic Access Control Policy

Owner: Information Security  
Review cycle: annual  
Last reviewed: 2024-01-15

Access to production systems must use individually assigned identities and
multi-factor authentication. Privileged access must be approved by the system
owner and reviewed quarterly. Joiner, mover, and leaver requests must be
recorded in the service-management system.

The organisation has not yet documented an emergency-access review procedure.
The supplied demonstration evidence contains no completed quarterly privileged
access review for 2026. These are intentional gaps in this synthetic policy.
