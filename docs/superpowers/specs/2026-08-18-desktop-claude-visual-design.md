## 0. 这次改什么，为什么

上一轮（8-13）解决的是「毛胚」——字阶、层级阶、组件边界。结构性问题已经没有了，剩下的是**观感目标本身上移**：从"不毛胚"提到"像 Claude macOS 客户端"。

本轮换三样东西：**色板转暖**、**信息架构改成 Claude 形态（左栏导航 + 居中限宽单栏）**、**把上一轮欠的两个视图一次还清**。

### 0.1 明确推翻的上一版结论

诚实登记，避免后来者以为是漏读文档：

| 上一版结论 | 本轮处置 | 依据 |
|---|---|---|
| §0.1 非目标「不换配色方案 —— 深色 + teal 成立」 | **推翻**。改为暖米白 + 赤陶，深色降为次选 | 使用者 2026-08-18 决定，观感目标上移 |
| §3.1 顶栏 48px 含主导航 | **推翻**。nav 下放左栏，顶栏压到 40px 只留拖拽区与两个开关 | Claude 形态无顶部 tab 栏 |

| §0.1 非目标「不做 ⌘K 命令面板 / 全局 toast / 快照测试」 | **保持** | 理由未变 |

## 1. 设计系统（token 层）

### 1.1 层级映射

`--layer-0..3` 的语义（沉底 → 浮起）不变，暖米白下明度方向反转——侧栏比主体**深**，卡片最亮。

| token | 现（冷深） | 改为（浅色主题） | 落点 |
|---|---|---|---|
| `--layer-0` | `#05070b` | `#F0EEE6` | 左侧会话栏（沉） |
| `--layer-1` | `#121826` | `#FAF9F5` | 主体画布 |
| `--layer-2` | `#1b2230` | `#FFFFFF` | 卡片 / composer |
| `--layer-3` | `#252d3d` | `#FFFFFF` + `--shadow-3` | 浮层 / 菜单 |
| `--text` | `#e9eef8` | `#1F1E1D` | |
| `--text-muted` | `#8b96ab` | `#6B6A66` | |
| `--text-faint` | `#5c6678` | `#87857E` | |
| `--border-0/1/2` | 冷蓝 8/14/22% | `rgba(60,50,40, .06/.10/.18)` | 边框全部转暖 |
| `--shadow-1/2/3` | 纯黑 | 暖影 `rgba(60,50,40, …)` | |

### 1.2 深色主题（保留，降为次选）

同步改成 Claude 的暖深灰，不再是蓝黑：

```
--layer-0 #1F1E1D   --layer-1 #262624   --layer-2 #30302E   --layer-3 #3A3A38
--text #F5F4EF      --text-muted #A8A69F   --text-faint #7A7873
```

默认主题跟随系统（`useUiPrefs` 现有能力），首次启动无系统偏好时落浅色。

### 1.3 accent 与状态色的形态分离（硬规则）

赤陶与告警色全是暖的，**色相分不开，所以按形态分**。这条写进 `tokens.css` 注释，约束后续所有组件：

- **accent 只做填充**——主按钮底、选中态底、focus ring。作文字时用加深版。**永不作状态点。**
- **状态色只做「点 + 文字」或细边框染色**，永不做大面积填充。
- **唯一例外**：降级浮出条与异常态状态栏 —— 那两处就是要抢注意力，允许整条染 `*-muted` 底（INV-38 要求降级显式可见，此处形态一致性让位于安全可见性）。

accent 分实底与文字两个值。**浅色实底刻意比 Claude 的 `#D97757` 深一档**：白字压在 `#D97757` 上只有 3.2:1，压在 `#C96442` 上也只有 3.9:1，两者都过不了 §5 判据 4。取 `#B4572F` 才到 4.8:1 —— 这是为对比度主动偏离 Claude 原色，不是取色取错。

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--accent` | `#B4572F` | `#D97757` | 实底。浅色配白字（4.8:1），深色配 `--text-inverse`（5.3:1） |
| `--accent-hover` | `#9E4B27` | `#E08B6B` | |
| `--accent-text` | `#A8492A` | `#E08B6B` | accent 作文字时（浅 5.0 / 深 5.1） |
| `--accent-muted` | `rgba(180,87,47,.10)` | `rgba(217,119,87,.14)` | 选中态底 |

状态色按亮底重算（不搬 Claude —— 它没有告警色需求）。**基准面是 `--layer-0`（`#F0EEE6`，浅色主题里最深的面，也是最坏情况），不是主体画布** —— 左栏与状态栏都坐在它上面。括号内为对 `--layer-0` 的实测对比度：

| token | 浅色 | 深色 |
|---|---|---|
| `--ok` | `#2A7353` (4.9) | `#5FBF8F` (5.9) |
| `--warn` | `#9C5D00` (4.6) | `#E0A038` (5.9) |
| `--danger` | `#B4241C` (5.6) | `#F08A80` (5.5) |
| `--info` | `#2C6BAA` (4.8) | `#6FA8DC` (5.3) |
| `--plan` | `#6D4FA8` (5.4) | `#A78BFA` (4.9) |

深色的基准面同理取**最亮的面** `--layer-2`（`#30302E`）。深色 `--danger` 不能用 `#E8695F`（只有 4.2）、`--accent-text` 不能直接复用 `#D97757`（只有 4.3）—— 两个都要提亮一档。

> 两个值都是压着线取的，别顺手调亮：`--ok` 用 `#2E7D5B` 在主体画布上有 4.7，**挪到左栏底上只剩 4.3**；`--warn` 用更好看的 `#A86400` 在主体上就只有 4.4。**改这两个值之前先跑 §4.2 的对比度测试。**

`--text-faint`（浅 `#87857E` / 深 `#7A7873`，约 3.1:1）**豁免于判据 4**，但随之定死一条规则：它只能承载装饰与已在别处出现过的冗余信息（相对时间、分隔符、占位符），**不得单独承载任何信息**。承载信息的最低档是 `--text-muted`（4.7:1）。

### 1.4 字体

```
--font-ui     -apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui   （不变）
--font-serif  ui-serif, "New York", Iowan Old Style, Georgia, serif          【新增】
--font-mono   ui-monospace, "SF Mono", …                                     （不变）
```

`--font-serif` **只用于视图标题与空态大标题**。数据、日志、状态、表单一律无衬线。Claude 的衬线味道靠这一点就够——用多了在安全工具里会读成"文艺腔"。

### 1.5 比例（"改得像"的关键，不是颜色）

Claude 的松是**字阶上移 + 内容限宽 + 行高放开**三件事一起给的。只换颜色会得到"暖色的旧界面"。

| 组 | 变更 |
|---|---|
| 字阶 | `base 14→15px` · `md 16→17` · `lg 20→22` · `xl 26→30` · `sm/xs/2xs` 各上移 1px |
| 行高 | `--leading-normal 1.5→1.6` · `--leading-relaxed 1.65→1.75` |
| 圆角 | `md 11→12` · `lg 16→18` · `xl 20→24`（composer）· 新增 `--radius-pill: 999px` |
| 间距 | 4px 基不变，新增 `--sp-12: 48px` / `--sp-16: 64px` 给画布留白 |
| 限宽 | 新增 `--measure: 46rem`（≈736px） |

字号仍受 `useUiPrefs` 的用户字号偏好缩放，机制不变。

### 1.6 兼容层删除

`tokens.css` 末尾那组 `--bg` / `--surface` / `--panel` 等旧别名是上一轮为 Settings / Evidence 留的。**本轮三视图迁完后当轮删除**，同时清 `styles.css` / `views.css` 中对应的遗留规则。见 §5 判据 1。

### 2.2 六条决策

1. **左栏 260px**，`--layer-0`。顶部「＋ 新建」与 composer 的「运行」是**全局仅有的两个** accent 实底按钮（其余一律 ghost / secondary）；会话列表 hover / 选中用 pill；底部分隔线下是「调查 / 证据 / 设置」三个视图入口。`⌘\` 收起。
2. **主体限宽 `--measure` 居中**。两侧留白直接吃掉上一版诊断里那片死区。**留白是 Claude 观感的主要来源**。窗口再宽内容不拉伸。
3. **composer 贴底浮起**：`--layer-2` 白底、`--radius-xl`、`--shadow-2`，不再嵌在栏里。档位选择器已是 Radix Select（上一轮换掉原生控件），本轮只调质感。
4. **右侧板可收起**，300px，只装「这轮跑出来的事实」（发现 / 证据 / 工具）——边界沿用上一版 §3.2，不动。
5. **状态栏贴底通栏 26px，跨全宽**，不可折叠、不随任何面板收起（INV-36 / INV-38 / M2 判据 10）。常态弱对比；`sandbox_impl: none` 或审计积压时整条染色 + 图标。
6. **证据 / 设置全屏替换主体区**，左栏与状态栏保持不动。不做 macOS 模态设置面板——Settings 的内容量装不进模态。

### 2.3 响应式

两档，不做更多断点：

- `<1180px` 自动收右侧板
- `<900px` 自动收左栏（顶栏 ☰ 唤回）

用户手动开关优先于自动，选择存进 `useUiPrefs` 跨会话恢复。

## 3. 组件与视图

### 3.1 primitives：只调质感，不改 API

十个 primitives 接口全部不动，消费方零改动，改的全在各自 `.css`：

| primitive | 改什么 |
|---|---|
| `Button` | 圆角转 pill；`primary` accent 实底 + 反色字；`ghost` hover 改暖灰 pill 底而非描边；**新增 `size="icon"`**（顶栏两个开关） |
| `ListRow` | **新增 `variant="nav"`**（左栏会话行与视图入口共用，选中 pill 底）；行高按新间距阶放开 |
| `Card` / `Panel` | `--layer-2` 白底 + `--border-0` + `--shadow-1`，去掉描边强调；圆角 `md→lg` |
| `Select` | 触发器改暖灰 pill；浮层 `--layer-3` + `--shadow-3` |
| `StatusDot` | 尺寸不变，色板换 §1.3 五色；**保持只有点 + 文字，不加底色** |
| `Field` | Settings 主消费方：标签字阶降一级、间距放开、`description` 走 `--text-muted` |
| `Disclosure` / `Timestamp` / `Tooltip` | 仅跟随 token，无结构改动 |

### 3.2 新增一个 primitive：`Prose`

Markdown 答案是主体区主角，需要独立排版容器：`--measure` 限宽、`--leading-relaxed`、标题走 `--font-serif`、代码块暖灰底、表格边框走 `--border-0`。现在这套散在 `styles.css` 里，借这轮收拢。

「看起来该新增」的 `SidebarItem` / `IconButton` 都用现有 primitive 加 variant 解决，**不开新文件**。

### 3.3 Settings 拆分（本轮工作量主体）

`SettingsView.tsx` 1454 行 → 一个壳 + 七个文件：

```
views/settings/
  SettingsShell.tsx      左侧竖排分区导航 + 内容区
  HubSection.tsx         focusSection 未指定时的落地页
  LlmSection.tsx         McpSection.tsx     SkillsSection.tsx
  AppearanceSection.tsx  DataSection.tsx    AboutSection.tsx
```

每个 150–250 行。分区导航从现在的 hub 卡片网格改成 Claude 惯例的**左侧竖排**（`ListRow variant="nav"` 复用）。

**拆分与美化分两次提交**：先按现有样式原样拆开、跑测试确认行为不变，再套新 primitives。拆错时回滚成本低。

### 3.4 `UiPrefsProvider`

`useUiPrefs` 升为 context。理由不是顺带重构——nav 下放左栏后，主题与字号要穿过三层新壳手传下去。收掉之后：

- `SettingsView` props 10 → 2（`focusSection` / `onProviderSaved`）
- `AppChrome` 不再接收 `themeLabel` / `onCycleTheme`

### 3.5 Evidence

改动最小：列表用 `ListRow`、详情用 `Panel`、整体限宽居中，哈希与路径保持 mono。功能不动。

### 3.6 CSS 收拢

`styles.css`（1227 行）与 `views.css`（617 行）随三视图迁移持续缩水，遗留规则本轮清空。见 §5 判据 6。

## 4. 测试

### 4.1 安全网

现有 **141 个渲染层测试 + 138 个 sidecar 测试全程不许变红**。primitives API 不变 → 多数测试天然存活。预期需改的只有三处：`AppChrome`（nav 下放）、`AppShell`（布局重排）、`SettingsView`（拆分）。

### 4.2 新增五组

1. **状态栏常显**（INV-36 / INV-38）：遍历「左栏收起 × 侧板收起」四种组合，断言六项状态始终在 DOM 且可见。
2. **降级注入用例**：`sandbox_impl: none` → 状态栏整条染色且带图标，不得只挂 tooltip；审计积压 > 0 → 待上报数可见。**这是安全语义测试，不是样式测试。**
3. **对比度断言**：解析 `tokens.css`，对五个状态色 + `--accent-text` + `--text` + `--text-muted` 逐一对 `--layer-0/1/2` 做 WCAG 计算，取最坏值，`≥4.5:1` 才过；另测 `--accent` 实底配反色字 ≥4.5:1。`--text-faint` 按 §1.3 豁免，单独断言 ≥3:1。两种主题各跑一遍。二十行工具函数，长期挡住"顺手调浅一点"。
4. **响应式两档**：mock `matchMedia`，`<1180` 收侧板、`<900` 收左栏。
5. **偏好持久化**：手动开关的侧板 / 左栏状态存入 `useUiPrefs` 并跨会话恢复。

### 4.3 不做快照测试

沿用上一版结论：重构期每改一次样式就要重录，是负资产。

## 8. 不变量对照
